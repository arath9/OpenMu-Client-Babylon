# Original development fixtures

`evolution_body.glb` is an original cyan box torso, generated by
`bun tools/evolutionTorso.ts` from the repository root. Its geometry, material
and placeholder joints are procedural; the generator reads no legacy assets.
Use under the repository license. It contains 12 triangles, no textures and no
animations. It is a compatibility fixture, not final armor art.

The existing character rig replaces the placeholder skin at runtime. Only joint
slot 19 is used (MU spine bone 18 plus the skin-root slot). Visual fit and motion
must still be checked in the game.
